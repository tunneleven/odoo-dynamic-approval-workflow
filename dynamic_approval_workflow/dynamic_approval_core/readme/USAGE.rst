Usage
=====

1. Navigate to **Approvals > Configuration > Workflow Definitions**.
2. Create a new workflow definition and add approval steps.
3. Publish the definition once validation passes.
4. Bind the published workflow to a model/action under
   **Approvals > Configuration > Workflow Bindings**.
5. When a user triggers the bound action, the approval workflow activates
   and creates tasks for resolved approvers.
6. Approvers act on tasks from **Approvals > My Tasks**.
7. Monitor running instances under **Approvals > Instances**.
